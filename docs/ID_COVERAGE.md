## Efektler

`slowness, darkness, blindness, speed, nausea, glowing, haste, hunger, levitation, mining_fatigue, night_vision, regeneration, saturation, slow_falling, weakness` -> `minecraft:<ayni ad>` (1.21.1 MobEffects kayit adlari ayni; fatal_poison->poison, village_hero->hero_of_the_village).

## Hasar nedenleri

entityAttack (playerAttack/mobAttack), lava, fall, magic, fire, fireTicks, drowning, suffocation, projectile, contact, entityExplosion/blockExplosion, void, starve, wither, lightning, freezing, suicide, thorns, none/override (generic). Ters yon: IdMap.damageCause (DamageType yolu -> neden).

## Aileler (hasFamily / EntityQuery)

scriptlerde: `monster`, `duskwalker_creature`. DwEntity aileleri bp/entities type_family ile ayni; vanilla: monster=Enemy, mob, player, animal, undead, arthropod, inanimate, zombie, skeleton, illager, tur adi.
